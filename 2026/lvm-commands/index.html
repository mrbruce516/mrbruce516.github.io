Linux LVM 创建命令速查

主要以命令为主。层级关系：PV（物理卷）→ VG（卷组）→ LV（逻辑卷）

1. 查看磁盘与分区

1lsblk                 # 树状查看块设备
2fdisk -l              # 查看磁盘及分区表
3parted -l             # GPT 友好的查看方式

2. 准备分区（可选，也可直接用整块盘）

fdisk 方式（MBR）

1fdisk /dev/sdb
2# 交互：n 新建分区 -> t 改类型为 8e (Linux LVM) -> w 保存

parted 方式（GPT，推荐大盘）

1parted /dev/sdb mklabel gpt
2parted /dev/sdb mkpart primary 0% 100%
3parted /dev/sdb set 1 lvm on

3. 创建 PV（物理卷）

1pvcreate /dev/sdb1                  # 单个分区
2pvcreate /dev/sdb /dev/sdc          # 直接用整盘，多个一起建
3
4pvs                                 # 简要信息
5pvdisplay                           # 详细信息
6pvscan

4. 创建 VG（卷组）

1vgcreate vg0 /dev/sdb1                       # 单 PV
2vgcreate vg0 /dev/sdb1 /dev/sdc1             # 多 PV 组成一个 VG
3
4vgs
5vgdisplay
6vgscan

5. 创建 LV（逻辑卷）

1lvcreate -L 20G -n lv_data vg0              # 指定大小 20G
2lvcreate -l 100%FREE -n lv_data vg0         # 用完 VG 剩余全部空间
3lvcreate -L 10G -n lv_log vg0               # 再建一个
4
5lvs
6lvdisplay
7lvscan

LV 设备路径：/dev/vg0/lv_data（也可写作 /dev/mapper/vg0-lv_data）

6. 格式化文件系统

1mkfs.ext4 /dev/vg0/lv_data          # ext4
2mkfs.xfs  /dev/vg0/lv_log           # xfs

7. 挂载与开机自动挂载

1mkdir -p /data
2mount /dev/vg0/lv_data /data

写入 /etc/fstab（推荐用 UUID，避免设备名漂移）：

1blkid /dev/vg0/lv_data              # 拿到 UUID
2# 在 /etc/fstab 追加一行：
3# UUID=xxxx-xxxx-xxxx  /data  ext4  defaults  0 0

验证 fstab 是否正确（重要，写错会导致开机失败）：

1mount -a                            # 无输出即成功

8. 扩展 LV（在线扩容，常用）

1# 先扩 LV
2lvextend -L +10G /dev/vg0/lv_data            # 在原有基础上加 10G
3lvextend -l +100%FREE /dev/vg0/lv_data       # 用完 VG 剩余空间
4
5# 再扩文件系统（必须，否则大小不会变）
6resize2fs /dev/vg0/lv_data                   # ext4，可在线
7xfs_growfs /data                             # xfs，必须已挂载，按挂载点扩

若 VG 空间不够，先扩 VG（见第 10 节）。

9. 缩小 LV（需离线，谨慎）

1umount /data
2e2fsck -f /dev/vg0/lv_data          # 强制检查
3resize2fs /dev/vg0/lv_data 15G      # 先缩文件系统到 15G
4lvreduce -L 15G /dev/vg0/lv_data    # 再缩 LV 到 15G
5mount /dev/vg0/lv_data /data

xfs 不支持缩小，只能备份后重建。

10. VG 扩展 / 收缩

1vgextend vg0 /dev/sdd1              # 加入新 PV，扩容 VG
2pvmove /dev/sdb1                    # 迁移该 PV 上的数据到同 VG 其他 PV
3vgreduce vg0 /dev/sdb1              # 数据迁完后从 VG 移除 PV

11. 删除（按创建的逆序）

1umount /data
2lvremove /dev/vg0/lv_data           # 删 LV
3vgremove vg0                        # 删 VG
4pvremove /dev/sdb1                  # 删 PV

12. 快照（可选）

 1# 创建快照（大小决定可保存的变更量）
 2lvcreate -L 5G -s -n lv_data_snap /dev/vg0/lv_data
 3
 4# 从快照恢复
 5umount /data
 6lvconvert --merge /dev/vg0/lv_data_snap
 7# 重启或激活后合并生效
 8
 9# 删除快照
10lvremove /dev/vg0/lv_data_snap

13. 常用查看命令汇总

1lsblk
2pvs / vgs / lvs                     # 三件套，日常最常用
3pvdisplay / vgdisplay / lvdisplay   # 详细版
4df -hT                              # 查看已挂载文件系统使用情况

典型完整流程（从零到挂载）

1pvcreate /dev/sdb1
2vgcreate vg0 /dev/sdb1
3lvcreate -l 100%FREE -n lv_data vg0
4mkfs.ext4 /dev/vg0/lv_data
5mkdir -p /data
6mount /dev/vg0/lv_data /data
7# 写入 /etc/fstab 实现开机自动挂载
8blkid /dev/vg0/lv_data
